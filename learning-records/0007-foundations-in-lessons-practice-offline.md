# Foundations in lessons; practice offline

The learner clarified how teaching should serve the mission in the agentic era: lessons exist to make foundations and principles clear enough to judge and delegate work to coding agents. They already build fluency by running experiments and labs on their own code. Guided in-lesson TDD/coding practice paths are a poor fit and should stop.

**Implications:** Treat the TDD loop as a fundamentals floor, not a continuing practice curriculum inside HTML. Next lessons: one principle, one sharp example, cited primary source, light or no check — leave application to their repos. Update [[MISSION.md]] constraints accordingly. Prefer next foundations that unlock agent direction/review (specs, acceptance/safe-to-ship, skeleton, ops) over more red–green micro-steps.
