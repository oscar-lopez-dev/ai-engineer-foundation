# TDD lessons felt formulaic

The learner reported that TDD-related lessons feel too AI-styled: same structure, same explanation patterns, same resources, same exercise kinds, and too much conceptual overlap across lessons. This is a teaching-quality signal, not a content gap.

**Implications:** Stop cloning the 0003–0005 skeleton (classify → rewrite → quiz + Beck/Canon TDD + Pocock every time). Next sessions must vary format, primary source, and example surface; re-state prior TDD moves only by link, not by re-teaching. Prefer leaving the red–green loop for practice in a new format, or shifting topic, over shipping another twin lesson. See NOTES anti-sameness rules.
