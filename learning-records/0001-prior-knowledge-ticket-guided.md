# Prior knowledge: ticket-guided .NET, not independent design

Professional experience is .NET Core / C#, but work has been ticket-guided. That means implementation exposure — writing code that arrives as tasks — not demonstrated mastery of problem framing, slice bounding, architecture trade-offs, or operations. Do not skip Group 0–1 foundations; do not re-teach language syntax as if it were new.

This sets the floor for the first lessons: the bottleneck is owning the unit of work (a vertical slice a user can walk), not writing loops.
