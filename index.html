1. Interactive Lessons

Units of foundational judgment taught through lightweight, interactive HTML documents (Tufte-inspired typography, light mental-model checks, cited primary sources).

Lesson 0001 · Foundation

A vertical slice, not a layer

The unit of work is a thin path a user can walk, not an isolated table, endpoint, or component. Eliminates agent-generated technical layers that fail to integrate.

Lesson 0002 · Foundation

A tracer, not a prototype

Distinguish throwaway prototypes (answering an isolated feasibility question) from enduring tracer bullets (real, thin, end-to-end production path you keep).

Lesson 0003 · TDD Foundation

One failing test

Writing one test first versus bulk suites or code-then-test. How to scope agent prompts to exactly one failing assertion before product code.

Lesson 0004 · TDD Foundation

Only enough to pass

Write strictly the minimal production code needed to turn the failing test green, rejecting premature abstractions and speculative features.

Lesson 0005 · TDD Foundation

Next test, not the rest

How to sequence tests one move at a time, incrementally illuminating the system's edge cases without losing the feedback loop.

Lesson 0006 · Review & Acceptance Criteria

Criteria that can fail

A criterion is only reviewable if it is falsifiable. The gate question: "What would I observe if this were false?" Translates fuzzy requirements into binary gates.
