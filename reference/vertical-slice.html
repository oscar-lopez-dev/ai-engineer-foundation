Vertical slice

A thin path a user can walk, cutting through every layer that path needs — and nothing else.

Definition

A vertical slice is a narrow, complete path from a person’s intent to an observable result. It touches every technical layer that path requires (UI, API, data, and any AI call), but only as much of each layer as the path needs.

Wake’s cake: you serve a slice through the layers, not a whole layer of sponge. INVEST, 2003.

Not this

Horizontal layer Vertical slice
Create the documents table Employee asks, sees an answer from one PDF
Add POST /api/ask Unauthenticated caller is refused
Build AskForm.tsx No relevant passage → “I don’t know”
Wire the OpenAI client One question, one document, one answer

Done when

  • A person can walk the path (or a test can, at a public seam).
  • Acceptance criteria are observations, not “code exists.”
  • The slice is bounded: one actor, one success, one named failure or out-of-scope.
  • An agent could finish it in one context window without inventing the rest of the product.
